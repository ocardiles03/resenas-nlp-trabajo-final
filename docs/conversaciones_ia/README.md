# Conversaciones con la IA (Claude Code)

Todo el proyecto se construyó con Claude Code, un asistente de IA de Anthropic que corre en el computador de Orlando. No hay enlaces compartibles de esas conversaciones, así que se exportaron a texto.

**Qué contienen:** solo los mensajes de Orlando y las respuestas de Claude. Se quitaron las salidas de herramientas, el razonamiento interno y los mensajes automáticos; se redactaron el correo personal y los nombres de compradores.
**Cuándo se exportaron:** el 19 de noviembre de 2026. La parte de la conversación 07 posterior a esa fecha no está incluida.
**Por qué hay pocas respuestas de Claude por conversación:** buena parte del trabajo (leer archivos, correr código, editar) fue con herramientas, y esas salidas no se incluyen.
**Continuación de sesiones:** cuando una conversación se llenaba, el trabajo seguía en una sesión nueva con un resumen del avance. Por eso algunas empiezan con "Handoff". Las sesiones que eran copias de otra se omitieron.
